# v0.6.0 Release Notes

- CLI version flag: `market-signal-lab --version` now prints `market-signal-lab 0.6.0` and exits without requiring an input CSV.
- Packaging metadata: the project now declares a minimal setuptools build backend in `pyproject.toml`.
- Public license file: the project now includes a public MIT `LICENSE` file and matching project metadata.
- Research boundary: this release only changes packaging and CLI polish. Backtest behavior, report semantics, data provenance, and no-advice boundaries are unchanged.
