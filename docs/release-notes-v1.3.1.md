# v1.3.1 Release Notes

Market Signal Lab v1.3.1 is a minimal GitHub Pages landing increment.

## Changed

- Adds a root `index.html` entry page that links to the static sample gallery and key local docs.
- Keeps the landing page static: no JavaScript, no remote assets, and relative repository-local links only.
- Extends selfcheck coverage so the root landing and gallery preserve local-link and no-remote-asset constraints.
- Updates package and CLI version metadata to `1.3.1`.

## Boundaries

- No broker connection, live market data, forecasts, or buy/sell recommendations.
- The gallery remains a research-only static demo built from synthetic sample data.
