# v1.2.1 Release Notes

Market Signal Lab v1.2.1 is a public-demo polish release for the static sample gallery and fee-sensitivity artifact.

## Changed

- Clarifies the first screen of `reports/index.html` so cold reviewers know which artifacts to open first before installing the CLI.
- Strengthens leveraged ETF-like fixture caveats in the gallery and fee-sensitivity artifacts.
- Extends selfcheck coverage so the static gallery remains no-JavaScript, local-link-only, and free of remote assets.

## Boundaries

- No broker connection, live market data, forecasts, or buy/sell recommendations.
- All sample returns are historical/synthetic artifact checks and do not imply future results.
