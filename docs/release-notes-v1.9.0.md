# v1.9.0 Release Notes

v1.9.0 adds a deterministic cross-asset thesis-ledger evidence packet generated from the bundled sample CSV for `QQQ_LIKE`, `QLD_LIKE`, and `TQQQ_LIKE`.

## Added

- `reports/cross-asset-thesis-ledger.md` and `reports/cross-asset-thesis-ledger.json` are generated by `scripts/selfcheck.py`.
- The packet reuses the existing moving-average backtest, exposure review, scenario-risk interpretation, and scenario-card helpers for each placeholder symbol.
- The static gallery and docs map link to the new Markdown and JSON artifacts.

## Boundaries

- Offline and zero-dependency: no live data, remote assets, broker connection, account fields, order routing, or execution feature.
- Research-only: not investment advice, not trading guidance, not a recommendation, not a prediction, and not evidence of future returns.
- The sample symbols are placeholders from a synthetic static fixture, not real fund prices.
