Market Signal Lab v1.30.0 prepares the Assumption Ledger Summary for public review as a compact static handoff for assumptions, risk boundaries, evidence paths, and explicit non-claims.

## Added

- Added public landing, gallery, docs, and selfcheck links for the assumption-ledger-summary artifacts.
- Bumped package metadata and CLI version reporting to `1.30.0`.

## Boundaries

The assumption ledger summary is a static research-review artifact only. It does not provide live data, broker/account access, order routing, position sizing, forecasts, recommendations, trading signals, or investment advice.
