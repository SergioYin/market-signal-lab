# v0.7.0 Release Notes

- Documentation navigation: `docs/index.md` is now the canonical map for risk, metric, data, workflow, artifact, and release documentation.
- Documentation selfcheck: `python scripts/selfcheck.py` now validates local Markdown links across README and documentation files with a no-dependency checker before regenerating sample artifacts.
- Version metadata: `market-signal-lab --version` now prints `market-signal-lab 0.7.0`.
- Public boundary: this release only changes documentation navigation and validation. Backtest calculations, generated report schemas, sample-data provenance, and no-advice boundaries are unchanged.
