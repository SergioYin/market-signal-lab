## One-line description

Market Signal Lab is a zero-dependency, research-only reference repo for packaging static market-signal backtest artifacts with visible assumptions, methodology caveats, acceptance checks, and no broker or live-trading surface.

## Short share note

If you want a compact example of how to publish backtest-style research artifacts responsibly, Market Signal Lab shows a static demo, synthetic sample data, methodology-audit checklist, thesis-ledger acceptance output, and no-advice boundaries. Start with the three-minute review route, then run the local audit commands from a fresh checkout.

## What not to claim

Do not present the sample moving-average outputs as a profitable strategy, a future-return forecast, a buy/sell/hold recommendation, a live signal, or a suitability assessment for leveraged ETF-like products.

## Safe call to action

Open the static demo, inspect the methodology-audit caveats, run `python -m market_signal_lab.cli --validate-thesis-ledger`, and decide whether the artifact pattern is useful for your own research notes.
