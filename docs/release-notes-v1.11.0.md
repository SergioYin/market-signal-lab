# v1.11.0 Release Notes

Market Signal Lab v1.11.0 adds a cold-user evidence card for reviewing the checked-in public artifacts without running live workflows.

## Added

- `docs/cold-user-evidence-card.md`, a concise reviewer route through the static gallery, scenario card, thesis ledger, acceptance summary, risk boundaries, and data provenance.
- `docs/evidence-card-walkthrough.svg`, a static visual path for the same public artifact review.

## Boundaries

The evidence card is documentation for static research artifacts only. It does not fetch live data, connect to brokers, inspect accounts, create orders, size positions, forecast, recommend, or provide investment advice.
