# v1.3.0 Release Notes

Market Signal Lab v1.3.0 is a promotion increment for the public static demo.

## Changed

- Adds a static demo manifest that records the gallery entry point, local artifact inventory, and Pages-safe no-remote-asset contract.
- Promotes `reports/index.html` from the README and documentation map as the first screen for cold reviewers.
- Extends selfcheck coverage for required v1.3 gallery links, relative local targets, and no remote gallery assets.
- Updates package and CLI version metadata to `1.3.0`.

## Boundaries

- No broker connection, live market data, forecasts, or buy/sell recommendations.
- Leveraged ETF-like samples remain synthetic research fixtures. Daily reset and path dependency warnings still apply.
