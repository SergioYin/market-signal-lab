# v1.3.2 Release Notes

Market Signal Lab v1.3.2 is a small public-demo discoverability increment.

## Changed

- Adds the published GitHub Pages demo URL to the README first screen so cold reviewers have an immediate browser-first entry point.
- Adds the public static demo link to the documentation map.
- Preserves the local checked-in gallery path for offline review and artifact verification.
- Updates package and CLI version metadata to `1.3.2`.

## Boundaries

- No broker connection, live market data, forecasts, or buy/sell recommendations.
- The public demo remains a research-only static artifact surface built from synthetic sample data.
- Historical backtest/sample results are examples only and do not imply future returns.
