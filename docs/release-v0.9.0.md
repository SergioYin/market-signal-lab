# v0.9.0 Release Checklist

This checklist covers the public release readiness items for the v0.9.0 public-demo increment. It is intended for a reviewer who needs to understand what changed, which exact commands verify it, which artifact paths are part of the demo, and why the output remains research-only.

See [v0.9.0 Release Notes](release-notes-v0.9.0.md) for the concise public summary.

## Feature Summary

- `docs/split-sweep-walkthrough.md` gives beginners a static walkthrough for reading the split-sweep robustness report.
- The walkthrough links to checked-in sample Markdown, HTML, and JSON split-sweep artifacts with relative paths.
- `reports/index.html` gives a no-JavaScript static gallery that links to the walkthrough and checked-in sample artifacts.
- README, documentation map, artifact gallery, selfcheck, and tests include the walkthrough and v0.9.0 release docs.
- Package metadata and CLI version output identify this release as v0.9.0.

## Verification Commands

Run every command from the repository root.

Confirm the source-tree version:

```bash
python -m market_signal_lab.cli --version
```

Expected output:

```text
market-signal-lab 0.9.0
```

Run the test suite:

```bash
pytest
```

Run the project selfcheck, which validates documentation links and regenerates sample artifacts:

```bash
python scripts/selfcheck.py
```

Expected selfcheck pass labels:

```text
PASS: compileall
PASS: pytest
PASS: sample artifact generation
PASS: documentation/gallery link check
PASS: v0.9.0 static demo acceptance check
PASS: public claim boundary check
Selfcheck completed.
```

Regenerate only the split-sweep demo artifacts:

```bash
python -m market_signal_lab.cli examples/data/sample_tqqq_qld_like.csv \
  --symbol QQQ_LIKE \
  --sweep \
  --short-windows 1,2 \
  --long-windows 2,3 \
  --fee-bps 10.0 \
  --top-n 3 \
  --split-ratio 0.5 \
  --output reports/sample-sweep-split.md \
  --json-output reports/sample-sweep-split.json \
  --html-output reports/sample-sweep-split.html
```

Regenerate the split-sweep demo from the checked-in config:

```bash
python -m market_signal_lab.cli --config examples/configs/split-sweep.json
```

Review the resulting workspace diff before publishing:

```bash
git status --short
git diff -- README.md docs/index.md docs/artifact-gallery.md docs/split-sweep-walkthrough.md docs/release-notes-v0.9.0.md docs/release-v0.9.0.md reports/index.html reports/sample-sweep-split.md reports/sample-sweep-split.json reports/sample-sweep-split.html
```

## No-Advice And Data-Provenance Boundaries

- Market Signal Lab remains research-only software. It does not provide investment advice, trading recommendations, forecasts, or live execution signals.
- The walkthrough describes how to inspect historical split-sweep diagnostics; it is not a strategy recommendation.
- `robustness_flag` labels compare historical train/test ranks and return gaps inside the supplied sample. They are review aids, not predictions, stability claims, or recommendations to buy, sell, or hold.
- `not_flagged` means only that deterministic review thresholds were not crossed in that sample; it is not a safety, suitability, or future-performance label.
- The bundled sample CSV remains synthetic example data with placeholder `_LIKE` symbols.
