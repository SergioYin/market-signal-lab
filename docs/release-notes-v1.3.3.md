# v1.3.3 Release Notes

Market Signal Lab v1.3.3 is a cold-review checklist increment.

## Changed

- Adds `docs/cold-review-checklist.md`, a 2-5 minute public review path for first-time visitors.
- Links the checklist from the README risk documentation and documentation map.
- Adds the checklist to selfcheck link/public-claim coverage.
- Updates package and CLI version metadata to `1.3.3`.

## Boundaries

- No broker connection, live market data, forecasts, or buy/sell recommendations.
- The checklist explains how to inspect static sample artifacts and caveats; it is not a trading plan.
- Historical diagnostics and sample results remain examples only and do not imply future returns.
