# v1.12.0 Release Notes

Market Signal Lab v1.12.0 packages the public promotion kit increment for sharing the checked-in static research artifacts without expanding the project into live trading, advice, or execution workflows.

## Added

- `docs/public-share-summary.md`, a public-safe overview of target users, a 60-second demo route, and research-only boundaries.
- `docs/reviewer-faq.md`, concise answers for cold reviewers about bot scope, live data, validation meaning, leveraged ETF-like examples, and first-open artifacts.
- `docs/promotion-checklist.md`, pre-share gates, evidence items, runnable checks, public-copy boundaries, reuse boundaries, and stop conditions.

## Changed

- Updates package and CLI version metadata to `1.12.0`.
- Registers the v1.12.0 release checklist and release notes in the public documentation surfaces and selfcheck link sources.

## Boundaries

The promotion kit is static documentation for public review of research artifacts only. It does not fetch live data, connect to brokers, inspect accounts, route orders, size positions, forecast, recommend, validate investment suitability, or provide investment advice.
