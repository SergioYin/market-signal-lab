# v1.18.0 Release Notes

Market Signal Lab v1.18.0 adds a small public-safe methodology-audit review-template increment. Reviewers can now generate a blank local JSON skeleton before filling PASS/WARN/FAIL statuses and scoring it with the existing methodology audit scorer.

## Added

- `market-signal-lab --methodology-audit-review-template`, which prints a blank static methodology audit review JSON skeleton to stdout.
- `--methodology-audit-review-template --json-output PATH`, which writes the same skeleton to a local JSON file without printing Markdown.
- Checked-in `reports/methodology-audit-review-template.json` generated by selfcheck.
- CLI tests for stdout JSON output, file JSON output, and invalid CSV/Markdown-output usage.

## Changed

- Updates package and CLI version metadata to `1.18.0`.
- Documents the new skeleton command in the methodology audit review schema, artifact gallery, documentation map, static gallery manifest, README, release docs, and selfcheck sources.

## Boundaries

This release remains deterministic and stdlib-only. It adds no JavaScript, no broker or account workflow, no live data, no orders, no position sizing, no recommendations, no forecasts, and no investment advice.
