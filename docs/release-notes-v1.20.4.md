# v1.20.4 Release Notes

Market Signal Lab v1.20.4 adds a static quick-tour preview for cold reviewers who want to understand the gallery path before installing or running the CLI.

## Added

- `docs/quick-tour-preview.md` with a three-minute visual route from static gallery to evidence card to thesis-ledger acceptance.
- `docs/quick-tour-preview.svg`, a no-JavaScript, no-remote-asset preview diagram designed for public sharing and README first-screen discovery.
- README, docs index, root landing, manifest, and selfcheck coverage for the quick-tour preview links.

## Boundaries

This is documentation/static-demo polish only. It does not add live data, broker/account/order workflows, position sizing, forecasts, recommendations, or investment advice. Sample backtest outputs remain historical diagnostics from synthetic/static fixtures and do not represent future returns.
